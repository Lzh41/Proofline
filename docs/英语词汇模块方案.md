# Proofline 英语词汇模块方案

## 目标

在 Proofline 内增加可离线使用的英语词汇训练。用户可设置每天学习的新词数、按难度选词；系统把新词与到期复习分开安排，并记录每个词的回忆结果与下次复习时间。

## 学习机制

1. **先回忆，再看答案**：每张词卡先隐藏目标词或中文释义。用户先在脑中提取，或输入拼写，确认后再揭示释义、英文定义、例句、搭配和词族。
2. **分散复习**：到期词优先进入当日训练。起始间隔采用 1、3、7、14、30 天作为产品启发式；评分“忘了、困难、记得、轻松”会影响后续间隔、难度因子和遗忘次数。固定间隔不是对所有人、所有词都最优的结论。
3. **词汇放进语境**：例句和搭配用于补足词性、常见用法与迁移；不以重复阅读例句替代主动回忆。
4. **难度分层**：词条保留 CEFR 等级与基础、进阶、高阶三档难度。CEFR 用于描述词汇范围，个人复习评分用于判断掌握情况。
5. **克制的游戏化**：每日目标、连续完成和词汇掌握进度反馈学习节奏；主要反馈仍以到期复习和延迟回忆表现为准，不按盲目新增数量奖励。

## 每日计划

- 每日计划新增“新词目标”，默认 10 个，可设为 0 到 100 个。
- 计划生成时按选定难度从尚未学习的词中挑选新词；已完成的新词不因重新生成计划而丢失。
- 到期复习单独计数，先于新词开始，不占用新词目标。
- 今日页分别显示新词进度与到期复习数量。

## 词条与复习数据

词条包含单词、音标、词性、CEFR 等级、难度、中文释义、英文释义、双语例句、搭配、词族、记忆线索、主题标签和来源。学习状态按词保存到期时间、当前间隔、难度因子、连续回忆数、遗忘次数和最近评分；每次复习另存方向、评分、回答、正确情况与耗时。

词库与学习记录进入应用快照、备份导入导出和 SQLite 结构表。内置词条以仓库中的自编内容为首版数据，不直接打包许可来源不清楚的抓取词典；后续扩充词库时需核对每个数据集、释义、例句及音频的授权并保留署名信息。

## 研究依据与边界

- 分散练习相较集中练习总体更利于延迟保持，但适宜间隔会随目标保持时长变化。产品因此采用可解释的起始间隔并按个人作答调整，而不宣称某一组天数普遍最优。
- 外语词对实验显示，在已答对后继续进行提取测试，延迟保持优于只继续学习。训练流程因此要求先回忆、后反馈。
- 词汇任务投入研究支持让学习者进行更深加工和主动产出。Hulstijn 与 Laufer 的阅读、填空和作文任务保持表现依次提高，但各任务耗时不同，不能把差异单独归因于写作产出。首版使用释义回忆、拼写产出、搭配与例句作为不同线索；它们是产品练习设计，不表示每种题型的效果已经在本应用中验证。
- 单句注释语境不一定比词对学习带来更高的整体词汇知识成绩。例句用于学习用法，并与回忆测试配合；它不替代主动回忆。
- 具体间隔序列、题型组合和积分反馈属于产品启发式，仍需通过用户的延迟回忆表现验证；目前没有证据证明本产品的游戏化或每项练习机制已经提升长期记忆。
